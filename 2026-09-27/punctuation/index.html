1. Quick Review: Two Independent Clauses

  • IC. IC.

    The sensor failed. The team repeated the test.

    Show analysis

    The sensor failed. The team repeated the test.

  • IC; IC.

    The sensor failed; the team repeated the test.

    Show analysis

    The sensor failed; the team repeated the test.

  • IC, FANBOYS IC.

    The sensor failed, so the team repeated the test.

    The first test was quick, but the second test took an hour.

    Show analysis

    FANBOYS = for, and, nor, but, or, yet, so

    The sensor failed, so the team repeated the test.

    The first test was quick, but the second test took an hour.

  • Comma splice

    The sensor failed, the team repeated the test.

    Show analysis

    ✗ 两个独立句之间只有一个逗号。

  • 一个主语，两个动词

    The team repeated the test and checked the results.

    The team repeated the test, and the results changed.

    Show analysis

    ✓ The team repeated the test and checked the results. — 一个主语，两个谓语，不加逗号。

    ✓ The team repeated the test, and the results changed. — and 后有新主语 → 两个独立句 → 逗号 + and。

Review 1

Which choice completes the text so that it conforms to the conventions of Standard English?

Before choosing: say the subject and verb on each side of the blank.

The first map showed only the city ______ second map also included nearby villages.
  1. center the
  2. center, the
  3. center. The
  4. center and the
Show answer
C. center. The
  • 左：The first map → showed。右：the second map → included。两边都是独立句。
  • B 单逗号 = comma splice；A 没有连接；D and 前缺逗号。

Review 2

Which choice completes the text so that it conforms to the conventions of Standard English?

Before choosing: say the subject and verb on each side of the blank.

A librarian started a book club for local teenagers. The first meeting attracted twelve ______ club now meets every Friday afternoon.
  1. readers the
  2. readers, the
  3. readers and the
  4. readers. The
Show answer
D. readers. The
  • 左：The first meeting → attracted。右：the club → meets。两个独立句。
  • B 单逗号 = comma splice。

Review 3

Which choice completes the text so that it conforms to the conventions of Standard English?

Before choosing: say the subject and verb on each side of the blank.

An old theater needed a new sign above its entrance. Local residents donated the ______ installed the sign during the summer.
  1. materials, volunteers
  2. materials and volunteers
  3. materials. Volunteers
  4. materials volunteers
Show answer
C. materials. Volunteers
  • 先找右边的谓语 installed → 它的主语是 Volunteers。
  • 左：Local residents → donated the materials。两个独立句。
  • B 把 materials and volunteers 读成一组宾语，installed 就没有主语了。

2. Attach a Dependent Clause

  • Dependent clause

    Because the sensor failed, the team repeated the test.

    Show analysis

    [Because the sensor failed], the team repeated the test.

  • 从属连词

    because · although · when · while · if · after · before · since · unless

    When the rain stopped, the students went outside.

    Show analysis

    [When the rain stopped], the students went outside.

  • DC, IC.

    Although the first result was unclear, the team kept the record.

    Show analysis

    [Although the first result was unclear], the team kept the record.

  • IC DC.

    The team repeated the test because the sensor failed.

    Show analysis

    The team repeated the test [because the sensor failed]. — 句末的 because 从句一般直接接，不加逗号。

  • 从句不能单独成句

    The team repeated the test. Because the sensor failed.

    Show analysis

    ✗ Because the sensor failed. — 不完整句（fragment）

    ✓ The team repeated the test because the sensor failed.

  • although 和 but 不同时用

    Although the test was short, but it was useful.

    Show analysis

    ✗ Although … , but …

    ✓ Although the test was short, it was useful.

    ✓ The test was short, but it was useful.

  • because 与 so

    Because it rained, the game stopped.

    It rained, so the game stopped.

    Show analysis

    [Because it rained], the game stopped. — 从属连词：DC, IC。

    It rained, so the game stopped. — 并列连词：IC, so IC。

Model 1

Find the dependent clause and the independent clause. Explain the comma.

When the students opened the box, the plants inside were already dry.
Show analysis
[When the students opened the box], the plants inside were already dry.
  • When 开头 → 从句（DC），不能单独成句。
  • the plants inside → were：独立句（IC）。
  • DC, IC → 逗号。

Practice 1

Correct the mistake.

Because the glass was dirty. The image looked blurred.
Show answer
Because the glass was dirty, the image looked blurred.
  • Because the glass was dirty 是从句，不能用句号单独成句。
  • 也可以：The image looked blurred because the glass was dirty.

Practice 2

Complete the sentence with the correct punctuation.

Although the sample was small ______ the researchers tested it twice.
Show answer
Although the sample was small, the researchers tested it twice.
  • Although … small 是前置从句；DC, IC → 逗号。

Practice 3

Correct the mistake.

Although the camera was old, but it took clear pictures.
Show answer
Although the camera was old, it took clear pictures.
  • although 和 but 只留一个。
  • 也可以：The camera was old, but it took clear pictures.

Application 1 · SAT

Which choice completes the text so that it conforms to the conventions of Standard English?

About 70,000 meteorites have been found on Earth. Although most meteorites are fragments of ______ hundred have been identified as being from the Moon or Mars.

meteorite：陨石；fragment：碎片；asteroid：小行星

  1. asteroids. Several
  2. asteroids, several
  3. asteroids; several
  4. asteroids: several
Show answer
B. asteroids, several
  • Although most meteorites are fragments of asteroids 是前置从句（DC）。
  • several hundred have been identified … 是独立句（IC）。
  • DC, IC → 逗号。

Application 2 · SAT-style

Which choice completes the text so that it conforms to the conventions of Standard English?

Researchers tested two materials that could be used to make lightweight bicycle helmets. Although the newer material absorbed less water than the material used in earlier ______ it offered the same level of protection during the laboratory tests.
  1. helmets;
  2. helmets,
  3. helmets.
  4. helmets, but
Show answer
B. helmets,
  • 从 Although 读到 helmets：整段是前置从句，中间的比较（less water than …）不影响。
  • it → offered … 是独立句；DC, IC → 逗号。
  • D 多了 but：although 和 but 不同时用。
