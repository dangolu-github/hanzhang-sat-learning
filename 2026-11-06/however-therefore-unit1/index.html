However and Therefore

Join Two Independent Clauses
Conjunctive adverbs

Joining Words

  • independent clause（IC，独立句）能单独成句；dependent clause（DC，从句）不能。
  • coordinating conjunction（并列连词，FANBOYS：and, but, so …）：加 comma（逗号）可以连接两个 IC。
  • subordinating conjunction（从属连词：because, although, when …）：把它所在的 clause 变成 DC。
  • conjunctive adverb（连接副词）和 transition（过渡词）：however, therefore, for example …，只表示关系，不连接 clause。

Meaning

  • however：contrast（转折）。
  • therefore：result（结果）。
  • for example：example（举例）。
  • The store opened earlyIC; however, nobody cameIC.
Test.
  1. 先盖住 however / therefore。
  2. 看左右两边：各有 subject（主语）和 finite verb（限定性动词），能独立成句吗？
  3. 两边都是IC，adverb（副词）在第二个IC开头 → 前面用 . 或 ;，后面加comma。
  • H1comma 不能连接两个 IC；加上 however 也不行（comma splice）。
    • The team practiced every day, however, it lost the final.
    • The team practiced every day; however, it lost the final.
  • H2therefore、for example 也一样。
    • It rained all morning; therefore, the game was moved indoors.
    • It rained all morning, therefore the game was moved indoors.
  • H3只想用 comma，就换成 coordinating conjunction（FANBOYS）。
    • The team practiced every day, but it lost the final.
    • It rained all morning, so the game was moved indoors.
