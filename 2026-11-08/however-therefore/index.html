However and Therefore

Join Two Independent Clauses

Short Practice

1. Correct the punctuation. Keep however.

Our bus was late, however, we still arrived on time.

Answer
Our bus was late; however, we still arrived on time. / Our bus was late. However, we still arrived on time.

2. Add the missing punctuation.

The gym was closed ___ therefore ___ we practiced outside.

Answer
The gym was closed; therefore, we practiced outside.（The gym was closed. Therefore, we practiced outside. 也对）

Find Where the Adverb Belongs
Where the adverb sits

Adverb Positions

  • 第二个 IC 开头：; however,
  • interrupter（插入成分）放在 clause 中间：前后 comma 成对。
  • 第一个 IC 末尾：, however; 或 , however.

Clause and Meaning

  • however 跟它表示 contrast 的那个 clause 在一起。
  • 没有 FANBOYS 时，两个 IC 之间的 boundary（边界）要 . 或 ;。
  • The referee, howeverinterrupter, stayed calm.
Test.
  1. 把 however 拿掉：剩下的 sentence 完整吗？
  2. 只有一个 IC，however 作 interrupter 且使用 comma 时 → 检查两个 comma 成对。
  3. 有两个 IC、没有 FANBOYS → 先在 boundary 放 . 或 ;，再看 however 属于哪一边。
  • H4用 comma 标出 interrupter 时，两个 comma 要成对。
    • The coach, however, was not worried.
    • The coach, however was not worried.
    • Our team, therefore, needs a new goalkeeper.
  • H5有两个 IC 时，however 留在它表示 contrast 的那个 IC 里；如果在这个 IC 末尾，however 后面才是 clause boundary。
    • Everyone expected rain. The sky stayed clear, however, the game started on time.
    • Everyone expected rain. The sky stayed clear, however; the game started on time.

Short Practice

1. Add one comma to correct the punctuation.

The library, however was closed on Sunday.

Answer
The library, however, was closed on Sunday.

2. Move however so that it compares the captain with the other players.

Many players were tired. The captain was not tired; however, he kept running.

Answer
Many players were tired. The captain was not tired, however; he kept running. / … was not tired, however. He kept running. / The captain, however, was not tired; he kept running. / However, the captain was not tired; he kept running.
Question 2 · H5, H1
Scala is referred to as a compiled programming language because it typically incorporates a compiler—a tool that translates lines of code into executable commands. Compiling isn’t exclusive to certain programming ______ any language can incorporate this tool.

Which choice completes the text so that it conforms to the conventions of Standard English?

  1. languages. However,
  2. languages; however,
  3. languages, however,
  4. languages, however;
Worked Answer

D. languages, however;

  1. 先盖住 however。左边 Compiling isn’t exclusive to certain programming languages 是 IC；右边 any language can incorporate this tool 也是 IC。两个 IC 之间只有 comma 不行（comma splice），排除 C。
  2. 右边 any language can … 是在 support 左边，不是 contrast，所以 however 不能放在右边开头，排除 A、B。
  3. contrast 在前一句和左边这个 IC 之间：Scala 因为有 compiler 才叫 compiled language，听起来只有某些语言才用；左边说并不是这样。所以 however 留在左边 IC 末尾，后面用 ; 连接两个 IC，选 D。
