# Hanzhang SAT Reading and Writing

Student-facing GitHub Pages site for Hanzhang's SAT Reading and Writing course. Hanzhang works on paper, so every handout and homework has a web version and a print-ready PDF.

## Routes

- `/` — Class Logbook (newest class first) and how to hand in homework
- `/<YYYY-MM-DD>/` — one class: Class Handout, Class Summary, HM
- `/<YYYY-MM-DD>/<handout>/` — handout web version, with its PDF in the same folder
- `/<YYYY-MM-DD>/<homework>/` — homework web version (answer online), its PDF, and the hand-in panel

## Hand-in

Homework can be handed in three ways: answering online (multiple choice is checked automatically), uploading photos or a PDF, or pressing “I sent it on WeChat” after sending photos to the teacher.

## Access and privacy

The learner enters the course password once in a browser; the browser keeps an opaque trusted-browser credential, never the password. The repository is public, so answer keys, model answers, teacher versions, learner responses, uploads and records stay in the private teacher service, outside this repository. All pages use `noindex` metadata.
